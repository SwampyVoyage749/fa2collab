# FA2SP 联机做图 · 使用说明

> 适用于 **FinalAlert 2 SP: HDM Edition 1.5.3**
> 版本 v0.4.0（2026-11-01）

---

## 一、这是什么

给 FinalAlert 2（红警地图编辑器）加的一个插件，让**两台电脑上的地编可以同时编辑同一张地图**：

- 你画的地形，对方屏幕上立刻出现
- 你能看到对方的鼠标位置、框选了哪片地
- 两个人涂到同一块地时，后涂的会被拒绝（红框提示），不会互相覆盖
- 改触发、改 INI 参数也会同步

> 本质是"共享一张画布"，不是"云端存档"。双方各自开着编辑器，改动用局域网实时互传。

---

## 二、安装（3 步，只做一次）

### 1. 备份原文件

进你的地编目录（里面有 `Syringe.exe`、`FinalAlert2YR.dat` 的那个），把原来的 `FA2sp.dll` 改名备份：

```
FA2sp.dll  →  FA2sp.dll.bak
```

### 2. 放入两个文件

从压缩包里复制这两个文件到地编目录：

```
FA2sp.dll          覆盖进去
FA2spCollab.ini    放在同一层
```

### 3. 修改配置

用记事本打开 `FA2spCollab.ini`，按下面的表改。

---

## 三、配置

```ini
[Collab]
Enabled=1              ; 1 = 启用，0 = 关闭
Host=1                 ; 1 = 我是房主（开房），0 = 我是加入方
HostAddress=127.0.0.1  ; 加入方填房主的 IP，房主填什么都行
Port=31415             ; 端口，通常不用改
Name=你的名字          ; 显示给对方看的名字

; ↓ 实验功能：删除的 INI 键也同步过去（默认关，先备份地图再开）
IniDeleteSync=0
```

### HostAddress 该填什么

| 场景 | 填什么 |
|---|---|
| 一台电脑开两个窗口 | `127.0.0.1` |
| 两台电脑连同一个路由器/WiFi | 房主的局域网 IP，形如 `192.168.1.23` |
| 两台电脑在不同地方（异地） | 用虚拟局域网（Radmin VPN 等）后，填房主的 `26.x.x.x` |

> 查自己 IP：命令行运行 `ipconfig`，看"IPv4 地址"。

---

### 更省事：一键配置（推荐）

不用手改 ini，双击 **`setup_collab.cmd`** 跟着提示走就行。

**它做什么**

1. 找到地编目录（拖文件夹给它 / 自动识别 / 弹窗选择）
2. 检查 `FA2sp.dll` 是不是联机版，不是就**自动备份并替换**（原文件存为 `FA2sp.dll.bak`）
3. 问你是房主还是加入方、名字、对方的 IP
4. 写好 `FA2spCollab.ini`

**流程长这样**

```
==== FA2 联机配置助手 ====

地编目录： D:\我的地编
联机模块： 已就位 (OK)
你是房主吗？(Y=房主 / N=加入方) [Y]: N
你的名字 [Beta]: 老王
房主的 IP（例如 172.19.163.2）: 172.19.163.2

已写入： D:\我的地编\FA2spCollab.ini
   [Collab]
   Enabled=1
   Host=0
   HostAddress=172.19.163.2
   Port=31415
   Name=老王
   ...

你是加入方，会连接到 172.19.163.2:31415
```

**房主运行完**，它会顺便列出本机所有 IP，直接挑一个发给对方：

```
你是房主。把你的某个 IP 发给对方（用哪个网络就发哪个）：
   26.212.46.173   (Radmin VPN)
   192.168.0.104   (以太网)
   172.19.163.2    (UU Lanplay)
```

**三种用法**

| 情况 | 怎么做 |
|---|---|
| 地编就在脚本旁边 | 直接双击 `setup_collab.cmd` |
| 地编在别处 | 把**地编文件夹拖到** `setup_collab.cmd` 上 |
| 拿不准 | 双击后弹窗里选文件夹 |

**注意**：只需 `setup_collab.cmd` 一个文件（脚本已内置），双击即可。

## 四、启动

两台机器都要做：

### 1. 打开地编

照你平时的习惯启动即可。命令行方式：

```cmd
Syringe.exe "FinalAlert2YR.dat" -o "你的地图.map"
```

### 2. 打开同一张地图

**两边必须是同一张图**。不要求路径相同，但文件内容要完全一致（程序会校验，不一致会拒绝连接）。

### 3. 处理弹窗

第二台机器启动时会弹出 `FA2sp Init Checker` → **点「是」**。
（这是 FA2sp 自带的单实例保护，不影响联机。）

### 4. 顺序建议

**先开房主，等它把图读完（10~30 秒），再开加入方。**

## 五、成功的样子

左上角会出现一条黑底状态栏：

```
Collab  你的名字 (host)   online:1   conflict:0   ini-conflict:0
  对方名字 (195,202)
```

- `online:1` = 有 1 个人连着
- `conflict:0` = 目前没有抢地冲突
- 下面一行 = 对方的光标在哪个格子

画面上还会出现：

| 视觉元素 | 含义 |
|---|---|
| 青色小圆点 + 名字 | 对方的鼠标位置 |
| 橙色虚线框 | 对方框选的区域 |
| 红色虚线框 | 你俩抢同一块地，你这边被拒绝 |

## 六、怎么一起干活

| 你做的动作 | 对方看到的 |
|---|---|
| 涂地形 / 撒矿石 | 立刻跟着变 |
| 移动鼠标 | 你的光标点亮起 |
| 框选一片地 | 橙色框出现 |
| 改触发参数 / 改 INI | 同步过去 |
| 放单位、建筑 | 约半秒后出现在对方画面（v0.4 起） |

### 分工建议

因为两个人的改动会互相覆盖同一块区域，实际使用时最好**按区域分工**：

- A 负责左上角，B 负责右下角
- 或者 A 负责地形，B 负责触发

万一涂到同一块，程序会把后涂的操作挡掉并提示，不会把地图搞坏。

## 七、一台电脑也想试试？

不需要两台机器，本喵准备了一个脚本，一键开两个窗口（相当于两个人）：

```
把地图文件拖到 start_two_instances.cmd 上
```

或者命令行：

```cmd
start_two_instances.cmd "D:\地图\测试.map"
```

它会自动：
1. 开房主窗口
2. 等 14 秒
3. 开加入方窗口
4. 自动点掉那个「FA2sp Init Checker」弹窗

然后把两个窗口**拖开摆好**，就能看到双方光标在动。

## 八、异地怎么连

程序只会在**同一个局域网**里互相找得到。跨网络需要先组一个"虚拟局域网"。

### 推荐：Radmin VPN（小蓝盾）

1. 两台机器都装 Radmin VPN，加入**同一个网络**
2. 各自会分到一个 `26.x.x.x` 的虚拟 IP
3. 房主的 `FA2spCollab.ini` 保持 `Host=1`
4. 加入方把 `HostAddress` 改成**房主的 `26.x.x.x`**

### 防火墙（通常卡在这一步）

如果加入方日志一直刷 `session not started (will retry)`，九成是防火墙。

在**房主**那台机器上，管理员权限执行：

```powershell
New-NetFirewallRule -DisplayName "FA2 Collab 31415" -Direction Inbound -Protocol TCP -LocalPort 31415 -Action Allow
```

或者把 Radmin 的虚拟网卡在网络设置里改成「专用网络」。

### 先测通不通

开地编之前先 ping 一下：

```cmd
ping 26.x.x.x
```

ping 不通 = 网络层没通，先解决这个，别急着开地编。

## 九、已知限制

| 限制 | 影响 | 说明 |
|---|---|---|
| 物件有约 0.5 秒延迟 | 放下的车/兵/建筑半秒后才出现 | 走 INI 节扫描，属正常；地形是 200ms |
| 删除的 INI 键不同步 | 你删掉一条触发，对方还在 | 改 `IniDeleteSync=1`（实验，先备份地图） |
| 同一条触发同时改 | 后改的覆盖先改的 | 会记冲突日志，但不会自动合并 |
| 没有房间界面 | 换名字/地址要改 ini 并重启地编 | — |
| 地图必须完全一致 | 差一个字节都连不上 | 传图时别用邮箱/QQ压缩，直接拷文件 |

## 十、出问题了怎么查

### 1. 看日志

地编目录下的 `FA2sp.log`，搜索 `[Collab]`。对照下表：

| 你看到的日志 | 含义 | 怎么办 |
|---|---|---|
| `[Collab] started` | 模块启动成功 | 正常 |
| `map ready: xxx.map hash=0x...` | 地图读取成功 | 两边 hash 应一致 |
| `hosting on port 31415` | 房主在等 | 正常 |
| `joining 1.2.3.4:31415` | 加入方在连 | 正常 |
| `peer joined: id=1 name=XX` | 连上了 | 成功 |
| `session not started (will retry)` | 连不上 | 查 IP、防火墙、房主是否已开 |
| `disconnected, retrying` | 断线了 | 会自动重连 |
| `chunk (x,y) owned by player N` | 抢地被拒 | 正常保护 |
| `protected chunk: restored N cells` | 被拒的改动被还原 | 正常 |
| `applied ini section [Structures]` → `object lists rebuilt: buildings=N` | 对方放的物件已落地并刷新画面 | 正常 |
| `object list rebuild crashed` | 物件重建出异常，该功能已自动关闭 | 存档重启地编，把日志发给作者 |

### 2. 崩溃了

地编目录下 `debug\snapshot-*\except.txt`，把这个文件留着。

### 3. 找人帮忙时给这些

1. 两边的 `FA2sp.log`
2. 如果有 `except.txt` 一起给
3. 一张截图
4. 一句话描述：做了什么、期望什么、实际什么

---

## 十一、卸载

删掉 `FA2spCollab.ini`，把 `FA2sp.dll.bak` 改名回 `FA2sp.dll` 即可，不留任何系统改动。

---

## 附：注意三件事

1. **只在副本上试**，别拿正在做的图直接联机
2. **两边同时开着时不要保存地图**（会互相覆盖），要保存先断开一方
3. 传图给对方的文件**必须是同一个文件**，不要中途用软件改过
