# 一键试玩（可行方案与原理）

> 目标：在 FA2 里改完图，不用手动找图、不用手动在列表里翻，
> 两下点击就能进游戏看效果。

## 结论先说

游戏内「真跑」的方式有三种，只有第三种在本机的 MO 安装里可行：

| 方式 | 能否 | 原因 |
|---|---|---|
| 编辑器内直接跑引擎（魔兽编辑器那样） | ❌ | FA2 与 gamemd 是两个程序，引擎无接口 |
| 命令行指定地图直接进遭遇战 | ❌ | 本机 gamemd.exe 没有 `-SP-MAP` 之类的启动开关（已用二进制搜索确认） |
| **写进地图列表 + 预选中** | ✅ | CnCNet 客户端按 `Client\SkirmishSettings.ini` 的 `Map=<sha1>` 预选地图 |

## 已验证的机制

1. 地图放进 `MapsMO\Standard\*.map` 就会出现在遭遇战列表里
2. `Client\SkirmishSettings.ini`：
   ```ini
   [Settings]
   Map=<地图文件的 SHA1，全小写>
   GameMode=<沿用原来的>
   ```
   **`Map` 的值就是该 .map 文件的 SHA1**（本喵用 720 张图逐一比对确认，命中了 `wheeloftorture.map`）
3. 启动 `MentalOmegaClient.exe` → 点「遭遇战」，列表里选中的就是这张图（已截图验证）

## 用法

```powershell
# 把图放进列表并预选中，同时启动客户端
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\playtest.ps1 -Map "D:\maps\mymap.map"

# 只放图、不启动
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\playtest.ps1 -Map "D:\maps\mymap.map" -NoLaunch
```

参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-Map` | （必填） | FA2 存出来的 .map 路径 |
| `-GameDir` | `D:\Mental Omega Normal - 副本` | MO 目录 |
| `-Name` | `collab_playtest` | 在列表里显示的文件名 |
| `-NoLaunch` | 关 | 只放图不启动 |
